Conceptual Understanding
What Is Actually Moving?
📦
What Is a Wave Packet?
A wave packet is a superposition of sinusoidal waves with a Gaussian distribution of wave numbers centered on k₀. The result is a localized disturbance: a fast carrier wave modulated by a slowly-varying envelope. Only the envelope carries information.
〰️
Phase Velocity — Speed of Crests
vₚ = ω/k is the speed at which each wave crest travels. In a dispersive medium, different frequency components move at different phase velocities, causing the packet to spread. vₚ carries no information and can exceed c without violating relativity.
📡
Group Velocity — Speed of Signal
vᷳ = dω/dk is the speed of the envelope peak. Since the envelope marks where energy is concentrated and where any encoded signal sits, vᷳ is the speed at which information and energy actually propagate. Fiber optics, radar, and quantum mechanics all operate at the group velocity.
⚡
Why Do They Differ?
In a dispersive medium ω ≠ vk — the curve is nonlinear. vₚ is the secant slope from the origin to (k₀, ω₀), while vᷳ is the tangent slope at k₀. Switch to Linear mode in the simulation to see them become equal when β=0.
🔬
Uncertainty Principle
A localized packet (small Δx) requires a wide k-spectrum (large Δk): Δx · Δk ≥ ½. This is the Heisenberg uncertainty principle in wave mechanics. Larger σₖ sharpens the packet spatially but broadens it in k-space. The readout tracks Δx · Δk live.
🌐
Real-World Applications
This principle governs fiber-optic pulse broadening in telecom, radar signal propagation, seismic wave analysis, quantum wave-packet evolution, and ocean swell forecasting. Engineers must control dispersion to prevent signal distortion.
Derivation
Mathematical Framework
1
Constructing the Wave Packet
The wave packet is a Fourier superposition of plane waves, each weighted by a Gaussian spectral amplitude A(k). The bandwidth σₖ controls the spatial width through the Fourier uncertainty relation. Smaller σₖ gives a wider, more monochromatic packet.
// Fourier superposition: ψ(x,t) = ∫ A(k) cos(kx − ω(k)t) dk
// Gaussian spectral envelope: A(k) = exp[ −(k−k₀)² / (2σₖ²) ]
// Fourier uncertainty relation: σₓ · σₖ = ½ (minimum uncertainty)
2
Dispersion Relation
The dispersion relation ω(k) governs how each Fourier component evolves. We use a quadratic relation representing a dispersive waveguide. With k₀=1, α=3, β=0.8: vₚ = 3.80 m/s and vᷳ = 4.60 m/s.
// Quadratic dispersion: ω(k) = αk + βk²
// Phase velocity — secant from origin: vₚ = ω(k₀)/k₀ = α + βk₀
// Group velocity — tangent slope: vᷳ = dω/dk|ₖ₀ = α + 2βk₀
3
Stationary Phase — Why Envelope Moves at vᷳ
// Phase of each k-component: φ(k) = kx − ω(k)t // Maximum constructive interference where phase is stationary in k: dφ/dk = 0 ⇒ x − (dω/dk)·t = 0 ⇒ x = vᷳ·t
xᵇᵗᵇᵉᵏᵆᵄ(t) = vᷳ · t ✓ (signal travels at group velocity)
// Phase crests satisfy k₀x − ω(k₀)t = const: xᵇᵕᵉᵗᵗ(t) = vₚ · t + const (crests travel at phase velocity)
4
Packet Spreading and Measuring Velocities
Dispersion (β ≠ 0) causes the packet to broaden because high-k components outrun low-k ones. We measure both velocities by linear regression on the tracked trajectories — slopes should match theory to <1%.
// Width broadening: σₓ(t) = σₓ(0)·√[1 + (β·σₖ²·t/σₓ²)²]
// Velocity measurement (linear regression): slope of xᵇᵗᵇ(t) → vᷳ measured slope of xᵇᵕᵉᵗᵗ(t) → vₚ measured |vᵏᵉᵃ − vᵗᵔᵉᵓ| / vᵗᵔᵉᵓ < 1% ✓

◆ CONCLUSION
The simulation confirms that in a dispersive medium (ω ∝ k²), phase velocity and group velocity are distinct and unequal. Individual wave crests travel at the phase velocity vₚ = ω/k, while the envelope — which carries the signal and energy — travels at the group velocity vᷳ = dω/dk. The stationary phase argument proves this analytically, and the simulation's linear regression measurements verify it numerically to within <1% error. Switching to linear dispersion (β = 0) makes vᷳ = vₚ, confirming dispersion is the sole cause of their separation. This principle governs fiber optics, quantum mechanics, radar propagation, and all wave-based communications.
